# 📚 Semana 10: Proyecto Final Integrador

## 🎯 Objetivos de la Semana

### Objetivo General

Desarrollar y presentar un proyecto final que integre todos los conceptos aprendidos durante el bootcamp, incluyendo API REST completa con HATEOAS, frontend básico y deployment profesional.

### Objetivos Específicos

- [ ] Implementar API REST nivel 3 (Richardson Maturity Model) con HATEOAS completo
- [ ] Integrar frontend básico que consuma la API
- [ ] Aplicar testing avanzado (unitarios, integración, E2E)
- [ ] Realizar deployment en plataforma cloud
- [ ] Documentar y presentar el proyecto de forma profesional

### 🧠 **1. Teoría**

- HATEOAS y Richardson Maturity Model nivel 3

### 🏋️ **3. Ejercicios**
