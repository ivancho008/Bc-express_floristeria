# Rúbrica de Evaluación - Semana 10

## 🎯 Proyecto Final Integrador

### Criterios de Evaluación

#### 1. API REST CON HATEOAS (30 puntos)

- Implementación completa de HATEOAS (Richardson nivel 3)
- Navegabilidad total entre recursos
- Autodocumentación de capacidades API
- Hipermedia controls correctos

#### 2. INTEGRACIÓN FRONTEND (25 puntos)

- Frontend funcional que consume la API
- Interacción correcta con endpoints HATEOAS
- Experiencia de usuario coherente
- Manejo de estados y errores

#### 3. TESTING Y CALIDAD (25 puntos)

- Suite completa de tests (unitarios, integración)
- Coverage adecuado (>80%)
- Tests de endpoints HATEOAS
- Documentación técnica completa

#### 4. DEPLOYMENT Y PRESENTACIÓN (20 puntos)

- Deployment exitoso en plataforma cloud
- Presentación técnica profesional
- Demostración funcional del proyecto
- Reflexión sobre aprendizajes obtenidos

### Escala de Calificación

- **90-100 pts**: Excelente
- **80-89 pts**: Bueno
- **70-79 pts**: Suficiente
- **0-69 pts**: Insuficiente
