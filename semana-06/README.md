## 🎯 Objetivos de la Semana

### Objetivo General

Desarrollar una API REST completa con operaciones CRUD avanzadas, relaciones entre entidades y manejo de datos complejos usando Express.js y base de datos.

### Objetivos Específicos

- [ ] **Implementar CRUD avanzado** con relaciones entre múltiples entidades
- [ ] **Manejar consultas complejas** con filtros, paginación y ordenamiento
- [ ] **Gestionar relaciones de base de datos** (1:1, 1:N, N:M) de forma eficiente
- [ ] **Aplicar validaciones avanzadas** para integridad de datos y business logic

## 📋 Contenidos

### 🧠 **1. Teoría (90 min)**

- CRUD avanzado y patrones de diseño
- Relaciones complejas entre entidades
- Consultas optimizadas y performance
- Validaciones de negocio y integridad de datos

### 💻 **2. Práctica (180 min)**

- Implementación de API completa multi-entidad
- Relaciones y foreign keys en acción
- Queries complejas con joins y filtros
- Manejo de transacciones y rollbacks

### 🏋️ **3. Ejercicios (90 min)**

- CRUD con validaciones avanzadas
- Sistema de roles y permisos básico
- Optimización de consultas
- Manejo de archivos y uploads

### 🎯 **4. Proyecto (90 min)**

- API E-commerce completa
- Productos, categorías, usuarios y órdenes
- Relaciones complejas implementadas
- Sistema funcional y documentado

## 🏆 Entregables

- [ ] **API REST completa** con mínimo 4 entidades relacionadas
- [ ] **Base de datos normalizada** con relaciones apropiadas
- [ ] **Documentación técnica** de endpoints y modelos
- [ ] **Testing manual** completo con casos edge
