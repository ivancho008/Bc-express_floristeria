## ✅ **Plan de Lectura - Semana 1**

### Antes de la Clase (Preparación)

**Objetivo**: Familiarizarse con conceptos básicos

1. **JavaScript.info** - Capítulo de Node.js (1h)

   - Solo lectura general, no profundizar
   - Identificar conceptos desconocidos

2. **The Node.js Handbook** - Capítulos 1-3 (45m)
   - Introducción y conceptos básicos
   - Setup inicial

### Durante la Semana (Consolidación)

**Objetivo**: Reforzar conceptos vistos en clase

3. **Node.js Notes for Professionals** - Capítulos relevantes (2h)

   - Consultar mientras se practica
   - Usar como referencia rápida

4. **Express.js Guide** - Secciones básicas (1h 30m)
   - Routing básico
   - Middleware fundamentales

### Después de la Semana (Profundización)

**Objetivo**: Ampliar conocimientos y preparar siguiente semana

5. **RESTful Web API Design** (1h)

   - Fundamentos de diseño API
   - Mejores prácticas básicas

6. **Eloquent JavaScript** - Capítulo 20 (1h)
   - Node.js en contexto
   - Módulos y asincronía

**⏱️ Tiempo total de lectura recomendado**: ~7 horas  
**📚 Distribuido**: 30-60 min diarios
