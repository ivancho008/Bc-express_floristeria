# 💻 Práctica Semana 4: Validación y Estructura

## 🎯 Objetivo

Implementar paso a paso validación con Joi y estructura Controllers/Services en ejemplos prácticos de 60 minutos cada uno.

## ⏰ Cronograma de Práctica (180 min totales)

### 📍 **Práctica 1: Validación con Joi (60 min)**

- **Tiempo**: 12:00 - 13:00
- **Enfoque**: Implementación básica de Joi
- **Entregable**: Middleware de validación funcionando

### 📍 **Práctica 2: Estructura Controllers/Services (60 min)**

- **Tiempo**: 13:00 - 14:00
- **Enfoque**: Separación de responsabilidades
- **Entregable**: API reestructurada profesionalmente

### 📍 **Práctica 3: Error Handling Centralizado (60 min)**

- **Tiempo**: 14:30 - 15:30 (después del break)
- **Enfoque**: Manejo consistente de errores
- **Entregable**: Middleware de errores implementado

---

## 🚀 Instrucciones de Uso

1. **Crear proyecto base**: `mkdir practica-semana4 && cd practica-semana4`
2. **Inicializar**: `npm init -y`
3. **Instalar dependencias**: `npm install express joi`
4. **Seguir cada práctica** en orden secuencial
5. **Probar cada paso** antes de continuar
